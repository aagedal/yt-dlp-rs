# Typed output templates and output paths

Exact official source target and unchanged baseline:
`897341241f2bfb2439fe0367f4c7c9ccd29a3828` (2026.08.19). No intervening
upstream commits; the global baseline is unchanged.

Inspected `options.py` `-P/--paths` and `-o/--output` (1396–1418) with
`_dict_from_options_callback` (268–295); `__init__.py` empty default template
handling (345–348); `utils/_utils.py` `OUTTMPL_TYPES`/`DEFAULT_OUTTMPL`
(2864–2880), `replace_extension` and `subtitles_filename`; and `YoutubeDL.py`
`get_output_path`, `_outtmpl_expandpath`, `_prepare_filename`,
`prepare_filename` (1216–1570), `_write_info_json` and `_write_subtitles`.
These files also cover `temp` paths with `MoveFilesAfterDownloadPP`,
thumbnail/description/annotation/link/chapter files and the `filename` compat
option, which are not implemented here.

Implemented: `KEY[,KEY]:VALUE` parsing with case-insensitive known keys,
otherwise the whole value for `default`/`home` (so `c:...` stays a template);
later values win per key; an empty default selects the default template
(upstream's `skip_download = None` is falsy). `prepare_filename` order is
template choice, `~`/`$VAR` template expansion, sanitized rendering, forced
type extension via `replace_extension` (`info.json`), trimming, the native
component guard, posix `join(home, type path, name)` with stripped/expanded
paths, then forced Windows path sanitization. Media uses no type path;
explicit templates such as `--print-to-file` FILE use only `home`. An empty
typed template skips that file (`[info] Skipping writing video subtitles`).
Absolute media templates warn that `--paths` is ignored.

Native differences: subtitles are written directly to the final
`subtitle`-template sidecar names rather than beside the temporary media file
and moved afterwards (the final layout is the same); `-P temp:` is rejected;
startup does not validate unused typed templates.

`tests/fixtures/paths/cases.json` has 15 argument sets × 4 kinds generated by
and re-checked against actual `parseOpts` + `prepare_filename`; the native
unit test covers 14 (the environment case runs as a CLI subprocess test).
