# Filename sanitization options

Exact official source target and unchanged baseline:
`897341241f2bfb2439fe0367f4c7c9ccd29a3828` (2026.08.19). No intervening
upstream commits; the global baseline is unchanged.

Inspected `utils/_utils.py` `ACCENT_CHARS` (100–102), `sanitize_filename`
(630–682), `_sanitize_path_parts`/`sanitize_path` (685–732); `YoutubeDL.py`
`_parse_outtmpl` (1206–1214), `get_output_path` (1216–1222), the
`prepare_outtmpl` sanitizer choice (1388–1404), `_prepare_filename` trimming
(1525–1553) and `prepare_filename`; `options.py` `--restrict-filenames`,
`--windows-filenames` and `--trim-filenames` (1431–1450); and
`test_utils.py` `test_sanitize_filename*`/`test_sanitize_path`. These mapped
files also cover `-P/--paths`, the `S` conversion, the `filename-sanitization`
compat option (`is_id`), Windows-host `sanitize_path`, the ASCII filesystem
encoding fallback and `final_ext`/`OUTTMPL_TYPES` extension handling, none of
which is implied here.

Implemented: upstream `replace_insane`, timestamp, repeated-substitute
collapsing and edge-stripping rules with the default `is_id` (so no `__`/`.`
post-processing); NFKC (ICU4X) and general-category C/M removal for restricted
names; the restricted default template; minimal non-Windows `/`/NUL handling
for `--no-windows-filenames`; forced non-Windows `sanitize_path` for
`--windows-filenames` over the whole rendered path; and `trim_file_name`
`rsplit('.', 2)` slicing before path sanitization, including negative lengths.

Native policy differences: a rendered path component that is dot/space-only
and not literally at the same position in the template becomes `_` (upstream
produces traversing paths such as `../x.mp4`); sidecar language/extension
components keep the native component sanitizer. Windows hosts later gained
upstream's Windows `sanitize_path` (`windows_sanitize_path`). Unicode data versions (ICU4X vs. Python's
`unicodedata`) may differ for newly assigned characters.

`tests/fixtures/sanitize/cases.json` holds 75 cases generated by and re-checked
against actual upstream `prepare_filename` (13 titles across default,
restricted, minimal, Windows and restricted+Windows modes plus default-template,
trimming and literal-path cases). Unit tests cover upstream `test_utils.py`
vectors; localhost CLI tests cover the flags, precedence, published names and
the containment guard.
